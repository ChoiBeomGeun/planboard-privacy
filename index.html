개인정보처리방침

운동 플랜보드 · 시행일 2026-10-08

운동 플랜보드(이하 "앱")는 사용자의 개인정보를 소중히 다루며, 다음과 같이 처리합니다.

1. 수집하는 정보

  • 계정 정보(선택) — 클라우드 동기화를 위해 로그인할 때만: 이메일 주소(이메일 코드 로그인), 또는 Apple 로그인 식별자와 Apple이 전달하는 이메일 주소(사용자가 '이메일 가리기'를 고르면 Apple의 전달용 주소)
  • 운동 데이터 — 사용자가 입력한 할 일·운동 종목, 주간 계획, 기상·근무 시간 설정, 일별 수행 기록, 감량 플랜을 쓰는 경우 체중 기록
  • 잠금화면 알림 정보(체크포인트 알림을 켠 경우) — Apple이 발급한 푸시 토큰, 앱이 무작위로 만든 기기 식별자, 오늘·내일 잠금화면에 보일 일정(시각, 할 일 이름, 안내 문구). 이름·이메일 같은 신원 정보는 들어 있지 않습니다.
  • 광고 정보(프로가 아닌 경우) — 광고를 보여 주는 Google AdMob이 수집합니다: 기기의 광고 식별자(iPhone은 사용자가 추적을 허용한 경우에만), IP 주소와 이를 바탕으로 한 대략적인 위치, 기기·운영체제·앱 정보, 광고 노출·클릭 기록. 개발자는 이 정보를 직접 받거나 보관하지 않습니다.
  • 앱 업데이트 확인 — 앱이 새 버전을 확인할 때 앱 버전 정보(런타임 버전, 현재 업데이트 ID)

로그인하지 않으면 운동 데이터는 사용자 기기에만 저장됩니다. 다만 체크포인트 알림을 켜 두면, 앱을 열지 않아도 잠금화면 보드가 제때 바뀌도록 위의 잠금화면 알림 정보가 개발자가 운영하는 서버로 전송됩니다.

2. 이용 목적

  • 계정 식별 및 로그인 유지, 로그인 코드 이메일 발송
  • 여러 기기 간 운동 데이터 동기화(로그인 사용자에 한함)
  • 정해진 시각에 잠금화면 보드(실시간 현황)를 바꾸는 알림 발송 — Apple 푸시 알림 서비스(APNs)를 통해
  • 프로가 아닌 사용자에게 광고 표시 — 맞춤 광고는 사용자가 허용한 경우에만
  • 앱 업데이트 제공

개인정보를 판매하거나, 개발자가 직접 마케팅 목적으로 이용하지 않습니다.

3. 보관 및 처리 위탁

  • Supabase Inc. — 계정·클라우드 동기화 데이터 저장. 서버 위치: 대한민국 서울(AWS ap-northeast-2). 암호화 연결(HTTPS)로 저장되며 계정 삭제 시까지 보관됩니다.
  • Google LLC (AdMob) — 광고 표시와 광고 성과 측정. 보관 기간은 Google의 정책을 따릅니다(Google이 파트너 앱의 정보를 사용하는 방식).
  • Google LLC (Gmail) — 이메일 로그인 코드 발송
  • Apple Inc. — Apple로 로그인, 푸시 알림(APNs) 전달
  • 잠금화면 알림 정보 — 개발자가 직접 운영하는 서버(대한민국 소재)에 저장됩니다. 지난 일정은 2일 뒤, 30일 동안 앱과 연결이 없는 기기 정보는 자동으로 삭제됩니다.
  • 서버 연결 — 앱과 서버 사이 연결은 암호화(HTTPS)되어 있으며, 네트워크 중계에 Tailscale(tailscale.com)을 사용합니다. 연결 과정에서 IP 주소 같은 통상적인 접속 정보가 처리될 수 있으나, 별도로 저장하거나 다른 목적으로 이용하지 않습니다.

4. 광고 선택권

  • iPhone — 추적 허용 요청을 거부하면 광고 식별자를 쓰지 않습니다. iPhone 설정 → 개인정보 보호 및 보안 → 추적에서 언제든 바꿀 수 있습니다.
  • 유럽연합·영국·스위스 — 처음 광고를 보여 주기 전에 동의를 묻고, 동의한 범위에서만 광고를 보여 줍니다. 앱의 설정 → 정보 → 광고 개인정보 선택에서 언제든 바꾸거나 철회할 수 있습니다.
  • 프로 이용자에게는 광고를 보여 주지 않습니다.

5. 삭제 방법

앱의 설정 → 계정과 동기화 → 계정 삭제에서 언제든 계정과 서버에 저장된 모든 데이터를 즉시, 영구적으로 삭제할 수 있습니다. 잠금화면 알림 정보는 설정 → 알림 → 체크포인트 알림을 끄면 서버에서 바로 지워지고, 앱을 삭제하면 30일 뒤 자동으로 지워집니다. 기기에 저장된 데이터는 설정 → 정보 → 앱 초기화, 앱 삭제 또는 브라우저 데이터 삭제로 제거됩니다.

6. 제3자 제공

위의 처리 위탁과 사용자가 허용한 맞춤 광고를 제외하고, 법령에 따른 요청이 아니면 개인정보를 제3자에게 제공하지 않습니다.

7. 유럽연합·영국 사용자(GDPR)

  • 개인정보 처리자 — 최범근(개인 개발자), 연락처는 아래 9번
  • 처리 근거 — 계정·동기화·알림은 서비스 제공(계약 이행), 맞춤 광고와 광고 식별자는 동의(언제든 철회 가능), 보안과 서비스 유지, 비맞춤 광고는 정당한 이익
  • 권리 — 열람, 정정, 삭제, 처리 제한, 이동, 반대, 동의 철회를 요청할 수 있고, 거주 국가의 개인정보 감독기관에 민원을 제기할 수 있습니다.
  • 국외 이전 — 데이터는 대한민국(Supabase 서울 서버, 개발자 서버)과 미국 등(Google, Apple)에서 처리됩니다. 각 사업자는 표준계약조항 등 법이 정한 보호 조치를 따릅니다.

8. 아동

앱은 만 14세 미만(유럽연합은 각 국가가 정한 나이 미만)의 아동을 대상으로 하지 않습니다. 아동의 정보가 수집된 사실을 알게 되면 지체 없이 삭제합니다.
