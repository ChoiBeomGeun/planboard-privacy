개인정보처리방침

운동 플랜보드 · 시행일 2026-09-27

운동 플랜보드(이하 "앱")는 사용자의 개인정보를 소중히 다루며, 다음과 같이 처리합니다.

1. 수집하는 정보

  • 계정 정보(선택) — 클라우드 동기화(프로 기능)를 위해 로그인할 때만: 이메일 주소, 소셜 로그인 식별자(Google/Kakao/Apple 제공 ID)
  • 운동 데이터 — 사용자가 입력한 운동 종목, 주간 계획, 기상/근무 시간 설정, 일별 수행 기록
  • 잠금화면 알림 정보(체크포인트 알림을 켠 경우) — Apple이 발급한 푸시 토큰, 앱이 무작위로 만든 기기 식별자, 오늘·내일 잠금화면에 보일 일정(시각, 할 일 이름, 안내 문구). 이름·이메일 같은 신원 정보는 들어 있지 않습니다.
  • 앱 업데이트 확인 — 앱이 새 버전을 확인할 때 앱 버전 정보(런타임 버전, 현재 업데이트 ID)

로그인하지 않으면 운동 데이터는 사용자 기기에만 저장됩니다. 다만 체크포인트 알림을 켜 두면, 앱을 열지 않아도 잠금화면 보드가 제때 바뀌도록 위의 잠금화면 알림 정보가 개발자가 운영하는 서버로 전송됩니다.

2. 이용 목적

  • 계정 식별 및 로그인 유지
  • 여러 기기 간 운동 데이터 동기화(로그인 사용자에 한함)
  • 정해진 시각에 잠금화면 보드(실시간 현황)를 바꾸는 알림 발송 — Apple 푸시 알림 서비스(APNs)를 통해
  • 앱 업데이트 제공

광고, 프로필 판매, 제3자 마케팅 목적의 수집·이용은 하지 않습니다.

3. 보관 및 처리 위탁

  • 클라우드 동기화 데이터 — Supabase(supabase.com) 인프라에 암호화 연결(HTTPS)로 저장되며, 계정 삭제 시까지 보관됩니다.
  • 잠금화면 알림 정보 — 개발자가 직접 운영하는 서버(대한민국 소재)에 저장되고, 알림은 Apple 푸시 알림 서비스(APNs)를 거쳐 기기로 전달됩니다. 지난 일정은 2일 뒤, 30일 동안 앱과 연결이 없는 기기 정보는 자동으로 삭제됩니다.
  • 서버 연결 — 앱과 서버 사이 연결은 암호화(HTTPS)되어 있으며, 네트워크 중계에 Tailscale(tailscale.com)을 사용합니다. 연결 과정에서 IP 주소 같은 통상적인 접속 정보가 처리될 수 있으나, 별도로 저장하거나 다른 목적으로 이용하지 않습니다.

4. 삭제 방법

앱의 설정 → 계정과 동기화 → 계정 삭제에서 언제든 계정과 서버에 저장된 모든 데이터를 즉시, 영구적으로 삭제할 수 있습니다. 잠금화면 알림 정보는 설정 → 알림 → 체크포인트 알림을 끄면 서버에서 바로 지워지고, 앱을 삭제하면 30일 뒤 자동으로 지워집니다. 기기에 저장된 데이터는 앱 삭제 또는 브라우저 데이터 삭제로 제거됩니다.

5. 제3자 제공

법령에 따른 요청을 제외하고 개인정보를 제3자에게 제공하지 않습니다.
